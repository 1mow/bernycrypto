# Berny Crypto Trainer

Telegram-бот + Mini App: обучающий симулятор крипто-трейдинга.

- **Mini App** (`public/index.html`) — само приложение: рынок из 50 монет по
  реальным на момент запуска курсам, портфель, кошельки, ежедневный бонус,
  история сделок.
- **Бот** (`index.js`) — витрина. Сам по себе он не даёт торговать: проверяет
  подписку на канал, показывает приветствие, инструкцию, «О проекте» и
  таблицу лидеров, а вся торговля происходит только внутри Mini App по кнопке.
- **Бэкенд** (тот же `index.js`, на Express) — раздаёт статику Mini App и
  хранит настоящую таблицу лидеров (реальные ники игроков бота), сверяя
  каждое обновление счёта по подписи `Telegram.WebApp.initData`, чтобы никто
  не мог подделать чужой результат.

Один процесс Node.js делает всё три вещи сразу — разворачивать нужно только
его, отдельный хостинг для сайта не требуется.

---

## 1. Создание бота в BotFather

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`, задайте имя
   `Berny Crypto Trainer` и юзернейм (например, `berny_crypto_bot`).
2. Скопируйте выданный токен — он понадобится в `.env` как `BOT_TOKEN`.
3. `/setdescription`, `/setabouttext`, `/setuserpic` — заполните карточку бота.
4. `/mybots` → выберите бота → **Bot Settings → Menu Button** → укажите
   адрес вашего Mini App (тот же `WEBAPP_URL`, см. ниже) — это добавит кнопку
   запуска приложения рядом с полем ввода сообщения (дополнительно к
   inline-кнопке, которую показывает сам бот в меню).

## 2. Канал для обязательной подписки

1. Создайте канал (или используйте существующий) с юзернеймом `@bernycrypto`.
2. Добавьте вашего бота в канал **администратором** — без этого бот не сможет
   проверять, подписан ли пользователь (`getChatMember` требует прав админа
   для непубличных проверок и вообще для надёжной работы в приватных каналах).
3. Если юзернейм канала другой — поменяйте `CHANNEL_USERNAME` и `CHANNEL_URL`
   в `.env`.

## 3. Установка и запуск

```bash
npm install
cp .env.example .env
# откройте .env и впишите BOT_TOKEN, CHANNEL_USERNAME, CHANNEL_URL, WEBAPP_URL
npm start
```

При старте увидите:

```
🌐 Mini App + API слушает порт 3000
🤖 Berny Crypto Trainer bot запущен (long polling)
```

Бот работает через long polling — отдельный домен для вебхука не нужен,
достаточно, чтобы процесс был запущен и имел доступ в интернет.

## 4. Деплой (чтобы WEBAPP_URL был публичным HTTPS-адресом)

Telegram требует, чтобы Mini App открывался строго по HTTPS. Подойдёт любой
хостинг, который держит долгоживущий Node-процесс, например:

- **Railway / Render / Fly.io** — подключаете репозиторий, задаёте
  переменные окружения из `.env.example` в панели хостинга, деплоите.
  Полученный публичный URL (вида `https://berny.up.railway.app`) и есть
  ваш `WEBAPP_URL`.
- **Обычный VPS** — `git clone`, `npm install`, `npm start` за pm2/systemd,
  домен + бесплатный SSL (Let's Encrypt/Caddy) спереди.

После получения постоянного `WEBAPP_URL`:
1. Впишите его в `.env` → `WEBAPP_URL` и перезапустите процесс — теперь бот
   покажет кнопку «🚀 Открыть Berny Crypto Trainer» в главном меню.
2. Впишите тот же адрес в BotFather → Menu Button (см. шаг 1.4).

> Важно: используйте **один и тот же** адрес и для `WEBAPP_URL`, и для Menu
> Button — так Mini App и бэкенд для таблицы лидеров будут на одном домене,
> и `public/index.html` сможет обращаться к `/api/leaderboard` без
> дополнительной настройки CORS.

## 5. Как устроена таблица лидеров

- Внутри Mini App при каждой активной сессии раз в ~15 секунд отправляется
  `POST /api/leaderboard/update` с текущей стоимостью портфеля и подписанным
  `initData` от Telegram.
- Сервер проверяет подпись (`verifyInitData.js`, HMAC-SHA256 по алгоритму из
  официальной документации Telegram) и только при успешной проверке
  записывает результат в `data/leaderboard.json` — так подделать чужой счёт
  или прогнать бота от чужого имени нельзя.
- Экран «Бонусы → Таблица лидеров» в приложении и команда `/top` /
  кнопка «🏆 Топ трейдеров» в боте показывают один и тот же реальный топ
  игроков (по никнейму или имени в Telegram).
- Если бэкенд временно недоступен (например, вы тестируете `index.html`
  локально без бота), приложение аккуратно откатывается на подписанные
  «демо» записи и не ломается — но это явно помечено в интерфейсе.

## 6. Ограничение на второй кошелёк

Создать второй (и далее) кошелёк можно только когда **суммарная стоимость
всех имеющихся кошельков** достигает **600 USDT**. Это логика самого
Mini App (`public/index.html`, `WALLET_UNLOCK_THRESHOLD`), проверяется на
клиенте при каждом открытии вкладки «Кошельки» — при необходимости порог
легко поменять одной константой.

## 7. Реальные курсы монет

Список из 50 монет и их стартовые цены (`public/index.html`, `COIN_DEFS`)
взяты из реального рынка на момент подготовки проекта. Дополнительно при
самом первом запуске (пока у игрока ещё нет сделок) приложение один раз
пытается подтянуть actual live-цены с публичного API CoinGecko — если это
не удаётся (нет сети, ограничения окружения Telegram) — используется
встроенный актуальный снимок, игра не прерывается. Дальнейшее движение
цен — симуляция (случайное блуждание с волатильностью и лёгким трендом на
каждую монету), а не биржевая лента: это тренажёр, а не терминал.

## 9. Частые вопросы

**Бот не видит подписку, хотя я подписан.**
Проверьте, что бот добавлен в канал администратором (шаг 2.2). Без этого
`getChatMember` может возвращать ошибку, и бот из соображений безопасности
считает пользователя неподписанным.

**Хочу убрать проверку подписки.**
В `index.js` замените вызовы `isSubscribed(ctx)` на `true`, либо просто
уберите условные `if (!subscribed) ...` блоки.

**Хочу другой порог для второго кошелька.**
В `public/index.html` найдите `const WALLET_UNLOCK_THRESHOLD = 600;` и
поменяйте число.

**Как сделать вебхук вместо long polling.**
Замените `bot.launch()` на `bot.launch({ webhook: { domain: WEBAPP_URL,
port: PORT } })` и настройте единый порт под вебхук и Express (либо
разверните вебхук как отдельный `app.use(bot.webhookCallback('/tg-webhook'))`
и вызовите `bot.telegram.setWebhook(WEBAPP_URL + '/tg-webhook')` один раз
вручную). Для учебного проекта long polling проще и надёжнее.
